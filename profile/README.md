## 🧠 Overview

Greenshot is a free, open-source screenshot tool for Windows that captures the full screen, individual windows, or custom regions with a single keystroke. It includes a built-in image editor for annotating captures and supports direct export to files, the clipboard, a printer, or external services such as Imgur and Confluence. It is developed by Greenshot Team. The product family is positioned as a screenshot and annotation utility toolset for Windows workflows.

Greenshot works as a Windows utility on Windows 10 and Windows 11 and is installed from a single package.

## 🚀 Key Features

| Feature | Description |
| --- | --- |
| 📸 Region Capture Mode | Lets the user drag a rectangle to capture any arbitrary screen area precisely. |
| 🪟 Window Capture | Captures a single application window, including its drop shadow, as a clean image. |
| 🖥️ Full-Screen Capture | Grabs the entire desktop in one keystroke, supporting multi-monitor setups. |
| ✏️ Built-In Image Editor | Opens captured images immediately for adding arrows, rectangles, text labels, and highlights. |
| 🔲 Obfuscation Tool | Blurs or pixelates selected regions to hide sensitive data before sharing a screenshot. |
| 📋 Clipboard Export | Copies the screenshot directly to the clipboard so it can be pasted into any application instantly. |
| 🔌 Plugin Export System | Sends screenshots to external destinations such as Imgur, Confluence, Jira, or a custom URL via plugins. |
| 📁 Configurable File Output | Saves captures automatically to a chosen folder using a user-defined filename pattern and format such as PNG or JPEG. |
| 🖨️ Direct Print | Prints a screenshot immediately to any installed system printer without opening a separate application. |
| 📐 Scrolling Capture via Plugin | Captures content that extends beyond the visible screen area in supported browser windows. |
